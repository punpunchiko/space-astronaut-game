# Don't Let the Alien Catch Ya!
## Project Option: Simple Browser Game
## Project Description: Similar to the Chrome Dinosaur Game, in this game, you play as a astronaut and jump over multiple colorful planets until getting to a certain score (precisely, 1750).
## Theme Interpretation: This directs to space because my main character is a astronaut, the obstacles you face are planets, and the CSS Styling is based on galaxies and stars.
## Intended User or Player: This project is designed for all ages from 7 and onward. It is a very simple game and a very easy objective to follow.
## User or Player Goal: The player should want to accomplish reaching the score needed (1750) to succeed in the game.
## Main Features: Start Menu (game objective and instructions), Randomized Obstacles (sends out random planets of different colors), Jumping Mechanism (java is used to allow players to jump at any given moment, especially for the obstacles).
## JavaScript Features: Game Engine Loop (handles collision with obstacles and restarting), Gravity/Jump Mechanism (waits for keyboard click to trigger the character to go up and down realistically), Event Handling (executes the reset button via a HTML button click).
## Responsive Design: The project will size down appropriately depending on whichever device a user is using.
## User Testing: Testing mainly focused on the scaling of the planets, making sure the objectives were clearly written out, checking that the reset mechanism was working fine, and CSS styling was aesthetically matched with the theme of the project.
## Revisions: 1) I added a Main Menu which I did not have before, 2) I changed the width of the planets to not have the warp/stretched look it had, 3) I added a reset button so players can easily reset the game to play again rather then refreshing every time.
## Technology Used: HTML, CSS, JavaScript, GitHub Pages
